## Принципы

- Минимализм: светлая нейтральная основа, один акцентный цвет, цвет несёт смысл.
- Доход и расход всегда различаются не только цветом, но и знаком (`+` / `−`) и стрелкой (▲ / ▼).
- Цвет категории одинаков на всех экранах и диаграммах.
- Окно: минимум 1280 × 720, боковая панель 232 px, область содержимого растягивается.
- Светлая и тёмная темы (тёмная — по возможности): значения ниже.

## Цвета интерфейса

Ключи ресурсов для `Resources/Colors.xaml` (светлая тема) и `Resources/Themes/Dark.xaml` (тёмная). Ссылаться на них через `DynamicResource`, чтобы тема переключалась на лету.

| Ключ | Назначение | Светлая | Тёмная |
|------|-----------|---------|--------|
| `AppBackgroundBrush` | Фон окна и области содержимого | `#F4F6F9` | `#0F141C` |
| `SurfaceBrush` | Карточки, шапка, таблицы, поля ввода | `#FFFFFF` | `#171E29` |
| `SidebarBrush` | Боковая панель | `#EEF1F6` | `#131923` |
| `BorderBrush` | Границы карточек, разделители | `#E1E5EC` | `#2A3341` |
| `InputBorderBrush` | Границы полей ввода и выпадающих списков | `#8A94A6` | `#5B667A` |
| `TextPrimaryBrush` | Основной текст, заголовки | `#1B2330` | `#E8ECF2` |
| `TextSecondaryBrush` | Подписи полей, второстепенный текст | `#44505F` | `#B4BDCB` |
| `TextMutedBrush` | Мелкие пояснения, подписи осей | `#5F6A7D` | `#98A3B5` |
| `AccentBrush` | Главная кнопка, ссылки, активные элементы | `#2F5FD0` | `#7FA2F2` |
| `AccentSoftBrush` | Выбранный пункт меню, значки-«таблетки» | `#E3EBFB` | `#1F2D4D` |
| `IncomeBrush` | Доход, рост, прибыль | `#1B7F4B` | `#5CC48A` |
| `ExpenseBrush` | Расход, убыток | `#B3261E` | `#F28B82` |
| `TrendBrush` | Линия тренда (пунктир) | `#C25A00` | `#F2A65A` |

Текст на кнопке с `AccentBrush`: белый (`#FFFFFF`) в светлой теме. В тёмной теме текст на `AccentBrush` — `#0F141C`.

    <SolidColorBrush x:Key="SurfaceBrush" Color="#FFFFFF"/>
    <SolidColorBrush x:Key="SidebarBrush" Color="#EEF1F6"/>
    <SolidColorBrush x:Key="BorderBrush" Color="#E1E5EC"/>
    <SolidColorBrush x:Key="InputBorderBrush" Color="#8A94A6"/>
    <SolidColorBrush x:Key="TextPrimaryBrush" Color="#1B2330"/>
    <SolidColorBrush x:Key="TextSecondaryBrush" Color="#44505F"/>

    <SolidColorBrush x:Key="AccentBrush" Color="#2F5FD0"/>
    <SolidColorBrush x:Key="AccentSoftBrush" Color="#E3EBFB"/>

## Шрифты и размеры текста

- Основной шрифт: **Segoe UI Variable** (Windows 11), запасной — **Segoe UI** (Windows 10). В макетах использован Inter: он близок по начертанию.
- Значки: **Segoe Fluent Icons** (символы шрифта, без картинок).
- Суммы в таблицах и показателях выравниваются по правому краю.

Ключи для `Resources/Typography.xaml`:

| Ключ | Назначение | Размер / межстрочный | Начертание |

| `ScreenTitleStyle` | Заголовок экрана | 24 / 32 | SemiBold (600) |
| `SectionTitleStyle` | Заголовок раздела на экране | 17 / 24 | SemiBold (600) |
| `WidgetTitleStyle` | Заголовок виджета | 15 / 20 | SemiBold (600) |
| `KpiValueStyle` | Показатель (чистый капитал и т. п.) | 28 / 34 | Bold (700) |

## Сетка, радиусы, размеры

- Отступы кратны 4: 4, 8, 12, 16, 24.
- Отступ содержимого экрана: 24. Расстояние между карточками: 16.
- Карточка: фон `SurfaceBrush`, граница 1 px `BorderBrush`, радиус **12**, внутренние отступы 18 × 20, без тени.
- Кнопки и поля ввода: высота **40**, радиус **8**.
- Переключатель периода и типа: фон `SidebarBrush`, радиус 10, внутренний отступ 3, кнопка высотой 34; активная кнопка — фон `SurfaceBrush`, текст `TextPrimaryBrush`, SemiBold.
- Пункт боковой панели: отступы 10 × 12, радиус 8; активный — фон `AccentSoftBrush`, текст `AccentBrush`, SemiBold.
- Строка таблицы: отступ 11 по вертикали, разделитель 1 px `BorderBrush`; заголовок таблицы — фон `AppBackgroundBrush`, текст 12 / 16 SemiBold `TextSecondaryBrush`.
- Индикатор выполнения цели: высота 8, радиус 4, фон `#E7EAF0`, заливка `IncomeBrush`.

## Кнопки

| Вид | Фон | Текст | Использование |
|-----|-----|-------|--------------|
| Основная | `AccentBrush` | белый, SemiBold | «+ Операция», «+ Счёт» |
| Переключатель (активный / неактивный) | `SurfaceBrush` / прозрачный | `TextPrimaryBrush` / `TextSecondaryBrush` | период, тип операции |
| Значок-кнопка (32 × 32) | прозрачный | значок `TextMutedBrush` | изменить счёт |

Все кнопки с одним значком имеют подпись для программы чтения с экрана (`AutomationProperties.Name`).

## Графики (LiveCharts2)

Строятся в `Charts/ChartFactory.cs`, цвета берутся из `Charts/ChartTheme.cs`.

- **Динамика капитала:** линия `AccentBrush`, толщина 2,5, точки радиуса 3,5; линия тренда — `TrendBrush`, пунктир 6 / 5, толщина 2; сетка `BorderBrush`.
- **Расходы по категориям:** кольцо, толщина сегмента 16; цвета сегментов — цвета категорий; в центре сумма за период; справа легенда (цвет, название, сумма).
- **Доходы и расходы:** столбцы по месяцам, доходы `AccentBrush`, расходы `#B87400`; тренд доходов — `TrendBrush`, пунктир.
- Всплывающие подсказки со значениями при наведении; подписи осей 11 px `TextMutedBrush`.

## Экраны

### Главная

Сетка из 3 столбцов, 3 ряда виджетов (порядок слева направо, сверху вниз):

1. Чистый капитал · Прогноз расходов · Инвестиции (показатель, изменение со стрелкой ▲ / ▼ и цветом);
2. Динамика капитала · Расходы по категориям · Доходы и расходы (графики);
3. Счета (по типам, итог) · Цели (индикаторы, остаток и взнос в месяц) · Последние операции (5 строк).

В шапке: заголовок, переключатель периода «Месяц / Квартал / Год», кнопка «+ Операция».

### Операции

Шапка: заголовок и «+ Операция». Панель фильтров: поиск по комментарию, период, счёт, категория, тип (Все / Доходы / Расходы / Переводы). Под ней таблица: дата, категория (цвет + название; подкатегория «Родитель · Подкатегория»), счёт (у перевода «Откуда → Куда»), комментарий, сумма. Над таблицей: «Найдено N операций» и итоги доходов и расходов. У перевода сумма нейтрального цвета (`TextSecondaryBrush`), без знака.

### Счета

Шапка: заголовок, флажок «Показать архивные», кнопка «+ Счёт». Сверху карточка «Всего на счетах». Ниже три группы (Дебетовые, Накопительные, Вклады): заголовок группы с итогом и карточки по 3 в ряд. В карточке: название, кнопка «Изменить», остаток, пояснение; у накопительного счёта — значок-«таблетка» привязанной цели, у вклада — ставка, срок и дата окончания.

## Для разработки

- Все цвета в XAML — только через ключи выше, без литералов `#RRGGBB` в `View`.
- Тексты и подписи — на русском; валюта — рубль. По ТЗ (п. 4.2) суммы отображаются **с двумя знаками после запятой**: в приложении `1 250 000,00 ₽` (неразрывные пробелы между разрядами, запятая как разделитель). В макетах копейки опущены для читаемости.
- Минимальный размер окна: `MinWidth="1280"`, `MinHeight="720"`.
